## 🔧 **Getting Started**

### **Prerequisites**
- Flutter SDK (>=3.2.3)
- Dart SDK
- Git

### **Quick Start**
```bash
# Clone the repository
git clone https://github.com/fabughali/my-cv.git
cd my-cv

# Install dependencies
flutter pub get

# Run in development mode
flutter run -d chrome

# Build for production
flutter build web --release
```
